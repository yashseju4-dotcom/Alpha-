# NexusForge PC — Web Development Project
## BCA / MCA (Integrated) Semester-I

**Topic:** Static 5-Page Website for a PC Build Shop  
**University:** Lok Jagruti Kendra University (as per given syllabus)

---

## Pages
1. `index.html` – Home (Hero, Features, Featured Builds, Stats, Video + Figure)
2. `builds.html` – Pre-built PCs + Comparison Table (with rowspan/colspan)
3. `components.html` – Components catalogue
4. `custom.html` – Custom Build Form (rich form with validation)
5. `contact.html` – Contact + About + Lists

---

## Syllabus Coverage (Detailed)

### Unit I – HTML Fundamentals
- Document structure (DOCTYPE, html, head, body)
- Headings, paragraphs, text formatting
- **Lists**: ordered (`<ol>`), unordered (`<ul>`), nested lists, **definition list** (`<dl>`, `<dt>`, `<dd>`)
- Hyperlinks (internal, external, **mailto:**)
- Images with `alt`, `src`
- **Tables** with `<caption>`, `<thead>`, `<tbody>`, `<th>`, `<td>`, **`rowspan`**, **`colspan`**
- HTML entities (₹, &amp;)
- Semantic HTML5: header, nav, section, article, figure, figcaption, footer, fieldset, legend

### Unit II – HTML Forms & Multimedia
- Form structure (`action`, `method`, `enctype`)
- Input types: **text, password, email, tel, number, date, radio, checkbox, file**
- Dropdown with **`<optgroup>`**
- Textarea + Button
- Validation attributes: **required, min, max, minlength, maxlength, pattern, title**
- **Fieldset + Legend** for grouping
- **iframe** (YouTube embed)
- **Figure + Figcaption**

### Unit III – CSS Fundamentals & Box Model
- External CSS + **Internal CSS** example
- Selectors (element, class, id)
- Pseudo-classes (`:hover`, `:focus`)
- Pseudo-elements (`::before`)
- Full Box Model (content, padding, border, margin)
- `box-sizing: border-box`
- Colors (hex, rgb/rgba, gradients)
- Typography & text properties

### Unit IV – CSS Layout (Flexbox & Grid)
- Display: flex, grid, block
- Position: sticky, relative, absolute
- Flexbox properties (justify-content, align-items, gap, flex-direction)
- CSS Grid (grid-template-columns, gap)
- Responsive units + **Media Queries**
- Mobile-first responsive design

## How to Run
1. Extract the ZIP
2. Open `index.html` in any modern browser (Chrome / Edge / Firefox)
3. No server or installation required
